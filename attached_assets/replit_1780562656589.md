# SuiKa — Burnout Recovery Companion (Complete Specification)

## What is SuiKa?

SuiKa is a premium, minimalist digital companion engineered to aid individuals recovering from chronic burnout, exhaustion, and nervous system dysregulation. It is an ultra-responsive, **mobile-first and laptop-first** web application that provides a quiet, "brutally minimal" dark-mode sanctuary reducing visual friction and cognitive overload.

SuiKa bridges individual subjective health and objective planetary-scale environmental data — allowing users to observe how their recovery cycles are influenced by local weather, air quality, pollen levels, and global environmental markers. By default, environmental data falls back to **Vienna, Austria (lat: 48.2082, lon: 16.3738)**.

The UI is built for laptops but automatically detects smartphone access and reflows its layout using CSS media queries.

---

## What can you do with SuiKa?

Core features are accessible from the **Home View** dashboard and the five main tabs:

* **Track Restorative Practices:** Countdown timer and stopwatch for meditation, tai chi, cardio, rest, voice/sound, or custom activities. A **synthesized gong sound** (Web Audio API) plays at the end of each timer session.
* **Map Physical Pain:** Interactive TCM body map (SVG, 18 tappable regions) with intensity (1–3) and duration logging.
* **Log Mental & Emotional States:** Mental pain (0–10), Soul State slider (contraction/fear → expansion/love), and Shutdown/Meltdown text field grounded in Polyvagal Theory, IFS, and Somatic Experiencing.
* **Correlate Environmental Strain:** Automated local environment profiles (AQI, barometric pressure, pollen count, daylight hours) linked to health logs.
* **Live Global Events:** Real-time disaster and climate alerts (GDACS + ReliefWeb) shown in the Earth tab.
* **Visualize Systemic Connections:** Interactive Systems Map with Pearson correlations, Loop Focus Mode.
* **Track Recovery Trends:** Multi-factor 7-day timeline charts downloadable as PNG.
* **Sensory Regulation Strategies:** Log and access strategies across 7 sensory channels.
* **Sync Across Devices:** MySQL-backed accounts — data accessible from any device after login.

## Production Architecture: World4You Shared Hosting

* **Frontend:** React 19 + Vite 7, compiled to static HTML/CSS/JS in `web/dist/`, served from subdomain root (e.g. `/www/suika.ybermorgen.org`).
* **Backend:** PHP 8.4 endpoints in `/api/`. No Node.js on the server.
* **Database:** MySQL/MariaDB via PHP PDO (`utf8mb4`). Managed via World4You Control Panel.
* **Auth:** PHP native `session_start()` + session cookies (`httponly`, `SameSite=Lax`, `Secure` on HTTPS).
* **Passwords:** `password_hash()` / `password_verify()` with `PASSWORD_BCRYPT`.

> **Node.js scope:** Only required locally on the developer's machine to run `npm run web:build`. Neither the server nor end-users need Node.js.

## ActionTab Feature Detail (`web/src/tabs/ActionTab.tsx`)

### Timer / Stopwatch

**Timer states:** `idle → running ↔ paused → complete`

**Timer mode:** `TimePicker` lets user set minutes (0–99) and seconds (0/15/30/45). `CircularTimer` SVG ring (size 240, stroke 12, accent color) shows countdown. Clicking the ring pauses/resumes.

**Stopwatch mode:** Shows elapsed time in `00:00` format. "Finish" button saves if elapsed ≥ 10s.

**Accuracy:** Uses `Date.now()` timestamps (`startedAtRef`) not `setInterval` tick counting. `visibilitychange` event re-syncs display when app returns to foreground.

### Gong Sound (`playGong()`)

Pure Web Audio API synthesis — no audio file. Three layered oscillators:

1. **Strike** (sine, 880→440 Hz, 0.08s frequency ramp, gain 0.6→0 in 0.25s)
2. **Resonant body** (sine, 110 Hz, gain ramps to 0.5 in 30ms, decays to ~0 over 3.5s)
3. **Second harmonic** (sine, 220 Hz, gain ramps to 0.2, decays over 2.5s)

`AudioContext` auto-closed after 4s. Only fires when `sessionMode === "timer"`.

### Timer Presets

Named durations stored server-side (`/presets`). `PresetsModal` allows add (name + minutes) and remove. Selecting a preset loads the duration into the timer.

### Post-Session Reflection (`ConnectionReflection`)

Prompt after every timer session: "Did you feel connected to anything beyond yourself?" Options: *Yes, deeply* / *Somewhat* / *Not today* / Skip. Saved via `PATCH /sessions/:id` with field `connectionReflection`.

### Regulation Section

Collapsible panel ("What could help right now?") with 7 channel groups. Strategies are toggle-chip buttons. Active strategies auto-saved to `/regulation-log` on each toggle. Users can add custom strategies per channel; delete with X button.

## InsightsTab Feature Detail (`web/src/tabs/InsightsTab.tsx`)

- **Timeline Chart:** SVG line chart across all logged days (not just 7). Lines: mental strain (indigo `#5856D6`), physical pain (white), practice minutes (green `#34C759`), soul state (violet `#AF52DE`), environment composite (cyan dashed `#5AC8FA`). Shutdown days shown as red dots. Downloadable as PNG via canvas serialization.
- **Formula Explanation:** Collapsible section explaining how Physical Pain, Mental Strain, Soul, Practice, Shutdown, and Environment scores are each calculated, with cited references.
- **Systems Map:** SVG network of 6 nodes connected by data-driven Pearson correlation edges (r > 0.3). *(See redesign proposal below.)*
- **Body Patterns card:** Top 5 TCM body regions ranked by cumulative weighted intensity across all logs. Shows region label and its meridian category. **Uses full spatial `bodyEntries` data — not just scalar pain totals** — revealing which body locations are most persistently activated.
- **Top Stressors card:** Frequency-ranked list of logged stress factors across all logs.
- **What Could Help card:** Frequency-ranked regulation strategies the user has most often selected.
- **Shutdowns/Meltdowns card:** Per-symptom frequency breakdown across all logs (brain fog, dissociation, freezing, shame, etc.)
- **Inner + Outer divider:** Section showing personal pain correlated against global ecosystem indicators (Arctic Ice, AMOC, Amazon) via a `CorrelationChart` component.
- **Planetary Vital Signs card:** Live data from `GET /nasa/planetary-health` — global temperature anomaly, CO₂ ppm, Arctic ice, ocean pH.
- **Sitting with Not-Knowing:** Daily rotating reflection quote (10 philosophical quotes selected by day-of-year index).

> **Body location data in Insights:** Every health log stores `bodyEntries` — a JSON array of `{ regionId, intensity, duration }` for each TCM region the user tapped. This spatial information is used in two ways: (1) computing the scalar `physicalPain` score via `derivePainFromEntries()`, and (2) populating the **Body Patterns** frequency card which shows *which locations* carry the most persistent load — a richer picture than pain level alone. This data is also available for future Systems Map enhancement (body-region cluster nodes).

## Systems Map — Construction Specification & Research Grounding

The Systems Map is an interactive SVG network diagram, implemented in `web/src/components/SystemsMap.tsx`, that visualizes how the dimensions of a user's recovery experience connect and influence one another. It is **not** a simple static diagram — it is a *data-driven relational system* that reads the user's personal health logs, timer sessions, and environment snapshots and calculates which connections are active in their specific life.

---

### Node Architecture

The map renders **9 nodes** in a concentric layout:

**Center node (integrating):**
- `soul` — Soul State (0 contraction/fear → 10 expansion/love). This is the central integrating node because it reflects the deepest quality of lived experience. All other dimensions either feed into it or emerge from it.

**Inner ring (direct daily experience, 4 nodes):**
- `physical-pain` — Physical Pain composite derived from TCM body map entries
- `mental-strain` — Mental Strain (self-rated 0–10 slider)
- `practice` — Total daily practice minutes (timer + manual log)
- `shutdown` — Shutdown/Meltdown event count per day

**Outer ring (context / body location, 4 nodes):**
- `environment` — Environmental Strain composite (pollen, AQI, pressure, temperature, daylight, humidity)
- `body-cognitive` — Cognitive Body Cluster: weighted intensity sum of regions `forehead`, `temples`, `eyes`, `jaw` (meridian: overthinking, decision fatigue, cognitive overload)
- `body-emotional` — Emotional Body Cluster: weighted intensity sum of `chest`, `throat`, `upper-back`, `solar-plexus` (meridian: grief, unspoken truths, heartache, anxiety)
- `body-depletion` — Core Depletion Cluster: weighted intensity sum of `lower-back`, `hips`, `knees`, `feet` (meridian: fear, burnout reserves, groundedness)

Node circle radius scales proportionally to the **standard deviation** of the node's value series across all logged days. Higher variability = more dynamic in the recovery process = larger node. Nodes with near-zero values are rendered smaller and at reduced opacity.

---

### Edge Architecture

Edges are of two types, visually distinct:

#### A. Structural edges — "established in literature" (dashed, low opacity)

These edges are always drawn regardless of user data. They represent relationships established by peer-reviewed research. Drawn as thin dashed lines in a muted color.

| From | To | Type | Research basis |
|------|-----|------|----------------|
| `mental-strain` | `physical-pain` | Reinforcing (+) | Gate Control Theory — Melzack & Wall, 1965 |
| `mental-strain` | `shutdown` | Reinforcing (+) | Polyvagal Theory — Porges, 2011 |
| `physical-pain` | `shutdown` | Reinforcing (+) | Polyvagal Theory — Porges, 2011 |
| `shutdown` | `soul` | Reinforcing (+, inverts soul) | Fragmented Selves model — Fisher, 2017 |
| `soul` | `practice` | Reinforcing (+) | Self-Determination Theory — Deci & Ryan, 2000 |
| `practice` | `physical-pain` | Balancing (−) | Morone et al., 2008; Garland et al., 2014 |
| `practice` | `mental-strain` | Balancing (−) | Hofmann et al., 2010 |
| `environment` | `physical-pain` | Reinforcing (+, lag +1 day) | Timmermans et al., 2015; Brown et al., 2017 |
| `environment` | `shutdown` | Reinforcing (+) | van den Berg et al., 2010 |
| `body-cognitive` | `mental-strain` | Reinforcing (+) | Levine, 2010; van der Kolk, 2014 |
| `body-emotional` | `soul` | Reinforcing (+, inverts soul) | van der Kolk, 2014 |
| `body-depletion` | `shutdown` | Reinforcing (+) | Levine, 2010 |

#### B. Personal data edges — lagged cross-correlation (solid, brighter)

For each pair of nodes, Pearson correlation is computed at time lags of 0, 1, 2, and 3 days. The lag with the **strongest absolute correlation** is selected. If that value exceeds **r = 0.35**, a directed edge is drawn with an arrow indicating the direction of influence and a lag label (e.g. "→ +1 day" or "← same day").

This lagged approach is essential: psychophysiological systems are not synchronous. A high-strain day today predicts pain tomorrow; a meditation session today improves mood over the following two days. Synchronous Pearson dramatically underestimates real connections in biological time-series data of this length.

Personal edges are drawn as solid bright lines on top of structural edges, using the same color as the node they originate from. Their stroke-width scales with |r|.

### Loop Detection & Narrative Labels

The map detects three named feedback loop archetypes by testing for the presence of their component nodes and edges:

| Loop name | Node sequence | Type |
|-----------|--------------|------|
| **Autonomy Erosion Cycle** | mental-strain → physical-pain → shutdown → soul ↓ → practice ↓ → mental-strain ↑ | Reinforcing (vicious) |
| **Recovery Spiral** | practice ↑ → mental-strain ↓ → soul ↑ → practice ↑ | Reinforcing (virtuous) |
| **Environmental Fragility Loop** | environment ↑ → physical-pain ↑ → shutdown ↑ → practice ↓ → mental-strain ↑ | Reinforcing (vicious) |

A **Loop Focus Mode** toggle button activates per loop. When active, only the nodes and edges belonging to that loop are highlighted at full opacity; all other elements fade to 10% opacity. A short narrative sentence describing the loop appears below the map.

*(Named after Donella Meadows' feedback loop archetypes from "Thinking in Systems", 2008.)*

---

### Node Layout

Concentric SVG layout with fixed polar positions:

- `soul` at center `(cx, cy)`
- Inner ring (4 nodes) at radius 110px, evenly spaced at 0°, 90°, 180°, 270°
- Outer ring (4 nodes) at radius 210px, offset by 45° from inner ring

SVG viewBox: approximately 500×500. Fully responsive (scales to container width).
